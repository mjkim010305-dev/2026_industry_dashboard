# LG전자 (lge.co.kr) UI/UX 분석

- 조사일: 2026-10-02 · 뷰포트 1440×900 · 국내 공식 브랜드숍 메인 기준
  (`lg.com/kr` 은 글로벌 사이트의 "페이지 없음" 화면으로 이동해 국내 사이트로 대신 조사)
- 방법: 화면 캡처 관찰 + 계산된 스타일 집계
- 브랜드 자산(로고·폰트·이미지)은 가져오지 않는다. 설계 원칙만 참고한다.

## 1. 전체 인상

쇼핑몰 성격이 강하다. 흰 바탕에 **둥근 흰 카드(16px)** 가 가로 캐러셀로 줄지어 있고,
브랜드 레드는 할인율·가격·배지에만 쓰인다. 정보 밀도가 높지만 카드 단위로 묶어 정돈된다.

## 2. 레이아웃

| 항목 | 관찰값 |
|---|---|
| 콘텐츠 최대 폭 | `1380px` (본문), 풀폭 영역 `1760px` |
| 헤더 | `120px`, 흰 배경. 위 줄 유틸(검색·계정·고객지원), 아래 줄 카테고리 메뉴 |
| 섹션 구성 | 히어로 배너 → 원형 아이콘 카테고리 바로가기 줄 → "MD's CHOICE"·"타임딜"·"베스트 랭킹" 카드 캐러셀 반복 |
| 섹션 머리 | 왼쪽 제목(24px) + 한 줄 설명, 오른쪽 "더보기 >" 링크 |
| 간격 | `8px` 기본 단위, `16px`, `28px` |

- 섹션마다 **제목 · 부제 · 탭(구매/구독) · 카드 줄 · 페이지 점(인디케이터)** 의 동일한 틀을 반복한다.
- 오른쪽 아래에 "맨 위로" 원형 버튼과 상담 버튼을 띄운다.

## 3. 타이포그래피

| 역할 | 크기 | 굵기 |
|---|---|---|
| 섹션 제목 | `24px/32px`, 자간 `-0.5px` | 700 |
| 카드 제목·본문 | `16px` / `14px` | 400~500 |
| 메타 정보(모델명 등) | `13px` / `12px`, 회색 `#727780` | 400 |
| 가격 강조 | `19px`~`22px` | 700 |

- 글꼴은 Pretendard 계열. 400 · 500 · 600 · 700 네 단계를 고르게 쓴다.
- 기본 글자색이 순검정이 아닌 `#111111`. 눈부심을 줄인 거의-검정.

## 4. 색

| 용도 | 값 |
|---|---|
| 글자 | `#111111` 기본, 보조 `#444444`, 메타 `#727780` |
| 바탕 | `#FFFFFF`, 면 구분 `#F3F5F7` (살짝 푸른 회색) |
| 브랜드 강조 | 레드 `#EA1917` — 할인율·배지·가격에만 |
| 주 버튼 | `#111111` 채움 + 흰 글자 |
| 보조 버튼 | 흰 바탕 + `#DEE1E5` 1px 테두리 |
| 딤 | `rgba(0,0,0,0.5)` |

## 5. 컴포넌트

- **카드**: 흰 바탕, `border-radius: 16px`, 아주 옅은 2중 그림자
  `0 2px 8px rgba(33,39,49,.05), 0 0 1px rgba(33,39,49,.28)` — 테두리처럼 보이는 1px 그림자 + 부드러운 확산.
- **탭(세그먼트)**: 알약형(`50px` 라운드), 높이 40px, 선택 = 검정 채움 / 미선택 = 흰 바탕 + 회색 테두리.
- **배지**: 카드 오른쪽 위 원형 레드 배지("최대 할인").
- **원형 아이콘 바로가기**: 카테고리를 원형 썸네일 + 아래 라벨로 가로 나열.
- **캐러셀**: 좌우 화살표 + 아래 점 인디케이터.

## 6. 모션

- 호버 `0.2s`, 배너 전환 `0.5s`~`0.8s`. 움직임은 적은 편.

## 7. 접근성 관찰

- "본문 바로가기" 건너뛰기 링크 제공(포커스 시 검정 바탕으로 나타남).
- `lang="ko"` 지정. 탭·버튼 높이 40px.

## 8. 우리 대시보드에 가져올 점

1. **둥근 흰 카드 + 1px 그림자 테두리**: 연결 폼·조종 화면·키보드 그림을 각각 카드로 묶는다.
2. **세그먼트 탭(알약형)**: 상단 페이지 이동 메뉴를 밑줄 탭 대신 알약형 세그먼트로.
3. **섹션 머리 틀 통일**: 제목(24px) + 한 줄 설명을 모든 구역에 같은 형태로.
4. **순검정 대신 `#111`, 면 구분은 푸른 회색 `#F3F5F7`**: 부드럽고 현대적인 인상.
5. **강조색은 의미가 있을 때만**: LG의 레드처럼, 우리는 상태(연결됨/실패)에만 색을 쓴다.
6. **건너뛰기 링크** 추가.
