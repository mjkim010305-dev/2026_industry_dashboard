# 대시보드 리뉴얼 디자인 가이드

다섯 곳(삼성 · LG · 애플 · 마이크로소프트 · 아마존)의 분석을 모아,
우리 세 페이지(`demo-video` · `teleop` · `survey`)에 적용할 규칙으로 정리한다.
각 규칙 옆 괄호는 근거가 된 사이트다.

> 원칙: 브랜드 자산(로고·전용 폰트·이미지·고유 색 조합)은 쓰지 않는다. 공통된 **설계 원칙**만 가져온다.
> 기능(영상 전환, bridge 연결, 키 입력, QR 확대)은 원본 코드 그대로 둔다. 바꾸는 것은 화면 모양뿐이다.

## 1. 다섯 곳의 공통점

## 2. 방향 — "로봇 시연 관제 콘솔"

- **머리**: 짙은 남색 상단 바(아마존·MS) — 얇고 고정(애플 44px+blur의 원리), 안에 알약형 세그먼트 탭(LG).
- **몸통**: 옅은 푸른 회색 바탕 + 흰 둥근 카드(LG·MS·아마존).
- **미디어 무대**: 영상·camera·map·QR 같은 "보는 것"은 검정 무대 위에(애플의 어두운 섹션).
- **강조**: 파랑 한 가지는 "누를 수 있는 것 · 현재 위치"에만(애플·MS). 상태색(초록·빨강)은 상태에만(아마존식 역할 분리).

### 간격 — 4의 배수 (MS)

`4 · 8 · 12 · 16 · 24 · 32 · 48px`. 카드 안쪽 여백 `24px`, 카드 사이 `16px`(좁은 화면 `12px`).

### 모서리

| 대상 | 값 | 근거 |
|---|---|---|
| 카드 | `16px` | LG · MS |
| 미디어 무대 | `12px` | 아마존 카드 |
| 입력칸·키 캡 | `10px` | 중간값 |
| 버튼·탭·칩 | `999px` (알약) | 삼성 · LG · 애플 · 아마존 |

### 그림자 — 2중 옅은 그림자 하나만

`0 0 1px rgba(14,23,38,.20), 0 2px 8px rgba(14,23,38,.06)` (LG · MS). 다크 모드에서는 그림자 대신 `1px` 테두리.

### 글자

| 역할 | 크기/행간 | 굵기 |
|---|---|---|
| 페이지 제목 | `32px/40px`, 자간 `-0.02em` | 700 |
| 카드 제목 | `18px/26px`, 자간 `-0.01em` | 600 |
| 본문 | `16px/24px` | 400 |
| 라벨·보조 | `14px/20px` | 500 |
| 메타 | `13px/18px` | 400 |

- 글꼴: `Pretendard → Apple SD Gothic Neo → Malgun Gothic → system-ui` (설치된 것 사용, 외부 파일 불러오지 않음).
- 굵기는 400 · 500 · 600 · 700 네 단계까지만.

### 모션

호버·포커스 `0.2s`(삼성 · 아마존보다 약간 여유), 콘텐츠 전환 `0.3s`(MS). 원본의 영상 자리 바꿈 애니메이션 `0.3s` 유지.

## 4. 컴포넌트 규칙

- **상단 바**: 높이 `56px`, `--appbar` 바탕, `position: sticky`, 반투명 + `backdrop-filter: blur(16px)`.
  왼쪽 프로젝트 이름, 가운데/오른쪽 알약 세그먼트 탭. 현재 탭 = 흰 채움 + 짙은 글자.
- **건너뛰기 링크**: 포커스할 때만 나타나는 "본문 바로가기"(LG · 아마존).
- **페이지 머리**: 작은 라벨(eyebrow, 13px 대문자 느낌) → 제목(32px) → 한 줄 설명. 세 페이지 모두 같은 틀.
- **카드**: `--surface` + 16px 모서리 + 그림자. 카드 머리 = 카드 제목(18px 600) + 오른쪽 보조 정보.
- **버튼**: 높이 `44px` 이상(애플·접근성), 알약형.
  - 주 = `--accent-fill` 채움 + 흰 글자 (예: 연결)
  - 보조 = `--surface` + `--line` 테두리 (예: 일시정지, 비밀번호 보기)
- **상태 표시**: 알약 칩 안에 아이콘 + 글자. 색만으로 구분하지 않고 항상 글자를 함께.
- **미디어 무대**: `--stage` 바탕, 12px 모서리, 위쪽 왼편에 라벨 칩(예: "map 이미지", "camera 영상").
- **키 캡**: `--surface-2` 바탕 + 아래쪽 2px 두께로 눌리는 키 느낌, 눌림 상태 = 파랑 바탕 + 흰 글자.

## 5. 페이지별 적용

| 페이지 | 바꾸는 것 |
|---|---|
| `demo-video` | 상단 바 · 페이지 머리 · 메인 플레이어를 검정 무대 카드로 · 제어 막대(재생 버튼 + 상태 칩 + 현재 영상) · 목록을 썸네일 카드 줄로 |
| `teleop` | 연결 설정을 카드로(입력칸 격자 정돈) · 상태 칩 · map/camera 무대 · 키보드 그림을 키 캡 스타일로, 키 그룹별 카드 |
| `survey` | 가운데 정렬 카드 하나에 안내 문구 + QR(흰 바탕 유지 — 스캔 대비) · 확대 창을 검정 무대로 |

## 6. 지키는 것

- 원본의 모든 `id` · 기능용 `class` · 스크립트는 그대로 둔다.
- 원본 접근성 장치(`aria-*`, `role`, 44px 클릭 영역, `:focus-visible` 외곽선, 숨김 제목 `.vh`)를 유지한다.
- 라이트/다크 모드 모두 대비 4.5:1 이상.
