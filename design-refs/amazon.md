# Amazon (amazon.com) UI/UX 분석

- 조사일: 2026-10-02 · 뷰포트 1440×900 · 미국 메인(한국어 표시) 기준
- 방법: 화면 캡처 관찰 + 계산된 스타일 집계
- 브랜드 자산(로고·폰트·이미지)은 가져오지 않는다. 설계 원칙만 참고한다.

## 1. 전체 인상

**기능 우선, 고밀도.** 짙은 남색 상단 바 두 줄(검색·계정 / 카테고리), 그 아래 큰 배너 위에
흰 카드 4열이 겹쳐 올라온다. 꾸밈보다 "찾기 쉽고 누르기 쉬운 것"에 집중한다.

## 2. 레이아웃

| 항목 | 관찰값 |
|---|---|
| 상단 바 | 1줄 `60px` 짙은 남색 `#131921`(로고·배송지·검색·계정·장바구니) + 2줄 `39px` `#232F3E`(카테고리) |
| 검색창 | 상단 바 가운데를 가장 넓게 차지. 높이 `38px`, 오른쪽에 주황 검색 버튼 |
| 본문 바탕 | 회색 `#F0F2F2`, 그 위에 흰 카드 |
| 카드 그리드 | 4열, 카드 폭 약 `298px`, 간격 `8~12px` — 배너 아래쪽에 겹쳐 올라오는 배치 |
| 최대 폭 | `1600px` |

- **회색 바탕 + 흰 카드** 구조로 카드 경계가 테두리 없이 분명하다.
- 각 카드 = 제목(24px) → 이미지(1장 또는 2×2) → "더 보기" 텍스트 링크. 틀이 완전히 같다.

## 3. 타이포그래피

| 역할 | 크기/행간 | 굵기 |
|---|---|---|
| 카드 제목 | `24px/32px` | 700 |
| 본문·링크 | `14px` / `15px` | 400 |
| 메타 | `12px` / `13px` | 400 |

- 굵기는 **400/700 두 단계만.** 글꼴은 시스템 기본(Arial).
- 본문이 14~15px로 작아 정보 밀도가 높다.

## 4. 색

| 용도 | 값 |
|---|---|
| 글자 | `#0F1111` (거의 검정), 보조 `#999999` |
| 링크 | 파랑 `#2162A1` |
| 상단 바 | `#131921` / `#232F3E` (짙은 남색) |
| 바탕 | `#F0F2F2` 회색, 카드 `#FFFFFF` |
| 주 버튼 | 노랑 `#FFD814` + 검정 글자 |
| 검색 버튼 | 주황 `#FEBD69` |
| 구분선 | `#DDDDDD` |

- **노랑 = 행동(로그인·구매)**, **파랑 = 이동(링크)** 으로 역할을 색으로 나눈다.

## 5. 컴포넌트

- **버튼**: 알약형(`100px`), 높이 `32px`, `13px`. 주 = 노랑 채움, 보조 = 흰 바탕 + 회색 `#888C8C` 테두리.
- **카드**: 흰 바탕, 모서리 `12px`(최근 개편으로 둥글어짐), 그림자 `0 2px 5px rgba(15,17,17,.15)`.
- **캐러셀**: 배너 좌우에 큰 화살표, 아래 상품 줄은 가로 스크롤.
- **"다음으로 건너뛰기"** 숨김 메뉴와 **키보드 단축키 안내**가 머리에 들어 있다(포커스하면 나타남).

## 6. 모션

- 전환 `0.1s` 정도로 아주 짧거나 없다. 반응 속도가 우선.

## 7. 접근성 관찰

- 키보드 사용자를 위한 **"다음으로 건너뛰기" 목록과 단축키 안내**가 있다(상단 h2로 확인).
- 버튼 높이 32px로 작다(터치 크기 권장 미달).
- `lang="ko-kr"` (언어 설정 반영).

## 8. 우리 대시보드에 가져올 점

1. **짙은 남색 상단 바**: 세 페이지의 공통 머리로 쓰면 "관제 도구" 느낌이 분명해진다.
2. **회색 바탕 + 흰 카드**: 테두리 없이도 구역이 분명. 라이트 모드 기본 구성으로 적합.
3. **색으로 역할 나누기**: 행동(연결 버튼) 색과 상태(연결됨) 색을 분리.
4. **카드 틀 통일**: 제목 → 내용 → 보조 정보 순서를 모든 카드에 똑같이.
5. **키보드 단축키 안내**: teleop 페이지의 키 그림이 바로 이 역할 — 더 눈에 띄게 다듬는다.
6. 버튼은 아마존처럼 작게(32px) 하지 않고 **44px 이상**을 지킨다.
