# 삼성전자 (samsung.com/sec) UI/UX 분석

- 조사일: 2026-10-02 · 뷰포트 1440×900 · 메인 페이지 기준
- 방법: 화면 캡처 관찰 + 계산된 스타일(getComputedStyle) 집계
- 브랜드 자산(로고·폰트 파일·이미지)은 가져오지 않는다. 설계 원칙만 참고한다.

## 1. 전체 인상

흰 바탕에 거의 검정에 가까운 글자, 제품 사진이 화면의 주인공이다. 장식은 최소화하고
**큰 제목 + 짧은 부제 + 알약(pill) 버튼 두 개** 조합을 섹션마다 반복한다.

## 2. 레이아웃

| 항목 | 관찰값 |
|---|---|
| 콘텐츠 최대 폭 | `1440px` (풀블리드 배경은 `1920px`) |
| 헤더 높이 | `64px`, 흰 배경, 로고 왼쪽 · 아이콘(검색·장바구니·계정·메뉴) 오른쪽 |
| 섹션 구성 | 풀폭 히어로(KV) → 제품 카드 그리드 → 다시 풀폭 배너, 교차 반복 |
| 그리드 간격 | `24px` 가 가장 흔함, 보조로 `8px` |
| 카드 | 연회색 `#F7F7F7` 바탕, 그림자 없음, 모서리 `8px` |

- 히어로는 텍스트를 가운데 또는 한쪽에 몰고 반대편에 큰 제품 이미지를 둔다.
- 카드에 테두리·그림자를 쓰지 않고 **배경 명도 차이만으로** 영역을 나눈다.

## 3. 타이포그래피

| 역할 | 크기 | 굵기 |
|---|---|---|
| 히어로 제목 | 약 `71px` (화면 비례로 커짐) | 700 |
| 섹션 제목 | 약 `44px` / `40px` | 700 |
| 소제목 | `24px`, 자간 `-0.02em` | 700 |
| 본문 | `16px` | 400 |
| 버튼·보조 | `14px` / `12px` | 400~700 |

- 굵기는 **400과 700 두 단계만** 쓴다. 중간 굵기는 거의 없다.
- 큰 제목일수록 자간을 살짝 좁힌다(음수 letter-spacing).

## 4. 색

| 용도 | 값 |
|---|---|
| 글자 | `#000000` (압도적), 보조 `#555555`, `#757575` |
| 바탕 | `#FFFFFF`, 면 구분 `#F7F7F7` |
| 주 버튼 | 바탕 `#000000`/`#212425`, 글자 흰색 |
| 강조(링크·포인트) | 파랑 `#007AFF` / `#2189FF` — 아주 적게 사용 |
| 딤(모달 배경) | `rgba(0,0,0,0.5)` |

- 색은 거의 흑백이고, 파랑은 "Available now" 같은 핵심 한 줄에만 쓴다.

## 5. 컴포넌트

- **버튼**: 알약형(`border-radius: 20px`), 높이 약 40px, 좌우 패딩 `24px`, 글자 `14px`.
  - 주 버튼 = 검정 채움, 보조 버튼 = 흰 바탕 + 1px 테두리. 항상 두 개를 나란히 둔다("더 알아보기" / "구매하기").
- **칩(필터·추천 키워드)**: `#F7F7F7` 바탕, `border-radius: 100px`, 패딩 `9px 12px`.
- **플로팅 버튼**: 오른쪽 아래 원형 AI 상담 버튼(`50%` 라운드).
- **그림자**: 페이지 전체에서 단 한 곳(`0 4px 10px rgba(0,0,0,.2)`). 그림자를 거의 쓰지 않는다.

## 6. 모션

- 전환 시간 `0.2s`(호버) · `0.5s`(콘텐츠 전환)가 기본. 배너 슬라이드는 `1s`.
- 짧은 호버, 느긋한 콘텐츠 전환으로 두 단계를 나눠 쓴다.

## 7. 접근성 관찰

- `lang="ko-KR"` 지정.
- 본문으로 건너뛰기 링크는 찾지 못했다.
- 버튼 높이가 40px 수준이라 권장 터치 크기(44px)보다 조금 작다.

## 8. 우리 대시보드에 가져올 점

1. **흑백 기반 + 강조색 한 가지**: 강조색은 상태(연결됨, 현재 탭)처럼 꼭 필요한 곳에만.
2. **테두리 대신 면 색으로 구역 나누기**: 회색 테두리 박스 대신 `#F7F7F7` 같은 옅은 면.
3. **알약형 버튼과 주/보조 쌍**: "연결"(주) / "비밀번호 보기"(보조) 같은 위계를 버튼 모양으로 표현.
4. **제목 크기 대비를 크게**: 페이지 제목과 본문 크기 차이를 확실히 벌린다.
5. **굵기 두 단계(400/700)만** 써서 정돈된 인상.
