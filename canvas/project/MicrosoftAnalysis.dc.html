UI/UX ANALYSIS · 마이크로소프트

Microsoft (microsoft.com/ko-kr) UI/UX 분석

  • 조사일: 2026-10-02 · 뷰포트 1440×900 · 한국 메인 기준
  • 방법: 화면 캡처 관찰 + 계산된 스타일 집계
  • 브랜드 자산(로고·폰트·이미지)은 가져오지 않는다. 설계 원칙만 참고한다.

1. 전체 인상

Fluent 디자인 계열. 흰 바탕에 둥근 카드(16~24px) + 아주 옅은 그림자, 파랑 버튼 하나. 제품마다 같은 카드 틀(이미지 → 제목 → 두 줄 설명 → 파랑 버튼)을 4열로 반복해 예측 가능하다.

2. 레이아웃

항목관찰값
헤더54px, 흰 배경, 로고 · 제품 메뉴 · 오른쪽 검색/장바구니/계정
최대 폭1600px (콘텐츠 1328px)
히어로왼쪽 큰 일러스트, 오른쪽 제목+설명+버튼. 아래 슬라이드 제어(이전/일시정지/다음)
카드 그리드4열, 간격 16px. 큰 프로모 카드는 2열(텍스트 카드 + 이미지 카드)
간격 체계4 · 8 · 16 · 24 · 48px (4의 배수)
  • 히어로 슬라이드 아래에 일시정지 버튼을 둔다. 자동으로 움직이는 콘텐츠를 사용자가 멈출 수 있다.
  • 히어로 바로 아래에 아이콘 + 라벨의 제품 바로가기 줄을 둔다.

  • 큰 제목은 500(medium), 카드 제목·버튼은 600(semibold). 700은 거의 안 쓴다.

  • 행간은 제목 1.17, 본문 1.5 정도로 일정한 비율.

용도값

  • 순검정 대신 푸른 기가 도는 짙은 남색을 글자색으로 써서 파랑 버튼과 잘 어울린다.

5. 컴포넌트

  • 버튼: 모서리 8px(알약 아님), 높이 40px(작게) / 48px(크게), 패딩 8px 16px / 12px 17px, 15px 600.
    • 주 = 파랑 채움 + 흰 글자, 보조 = 흰 채움 + 짙은 글자.
  • 카드: 흰 바탕, 모서리 16px/24px, 그림자 2중 0 0 2px rgba(0,0,0,.12), 0 2px 4px rgba(0,0,0,.14) — Fluent의 "깊이 4" 단계.
  • 슬라이드 제어: 원형 이전/다음 버튼 + 가운데 일시정지 버튼.
  • 아바타: 계정 이니셜을 원형 테두리 안에.

6. 모션

  • 전환 0.3s가 대부분, 호버 0.2s. 차분하다.

7. 접근성 관찰

  • lang="ko-KR". 큰 버튼 48px.
  • 자동 슬라이드에 일시정지 제어 제공(WCAG 2.2.2 충족 방식).
  • 키보드 포커스 시 굵은 외곽선(Fluent 포커스 링) 사용이 이 계열의 특징.

8. 우리 대시보드에 가져올 점

  1. 4의 배수 간격 체계(4·8·16·24·48): 세 페이지 간격을 하나의 체계로 통일.
  2. 카드 = 둥근 모서리 + 2중 옅은 그림자: 연결 폼, 조종 화면, 키 그룹을 같은 카드로.
  3. 제목 500 / 카드 제목 600 / 본문 400: 굵기로 위계를 분명하게.
  4. 짙은 남색 글자 + 파랑 강조: 로봇·기술 대시보드와 잘 맞는 차가운 톤.
  5. 움직이는 영상에 일시정지 버튼을 눈에 띄게: demo-video의 재생/일시정지 버튼을 플레이어 제어 막대로 정돈.
  6. 버튼 모서리 8px: 알약형보다 대시보드·도구 화면에 어울린다.
