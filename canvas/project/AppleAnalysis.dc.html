UI/UX ANALYSIS · 애플

Apple (apple.com/kr) UI/UX 분석

  • 조사일: 2026-10-02 · 뷰포트 1440×900 · 대한민국 메인 기준
  • 방법: 화면 캡처 관찰 + 계산된 스타일 집계
  • 브랜드 자산(로고·폰트·이미지)은 가져오지 않는다. 설계 원칙만 참고한다.

1. 전체 인상

제품 하나에 화면 하나. 섹션마다 큰 제목 한 줄, 짧은 부제 한 줄, 링크형 버튼 두 개만 둔다. 검정 섹션과 밝은 회색 섹션을 번갈아 놓아 리듬을 만든다. 장식·그림자·테두리가 거의 없다.

2. 레이아웃

항목관찰값
글로벌 내비높이 44px, 고정(fixed), 반투명 rgba(245,245,247,.8) + backdrop-filter: saturate(180%) blur(20px)
콘텐츠 폭텍스트 블록 980px/1024px, 이미지 영역은 최대 2560px 풀블리드
섹션화면 높이에 가까운 풀폭 타일, 텍스트는 가운데 정렬 상단 배치
타일 그리드아래쪽은 2열 타일, 타일 사이 간격 약 12px
  • 내비가 얇고(44px) 반투명이라 콘텐츠가 그 밑으로 비쳐 보인다. 화면 공간을 거의 먹지 않는다.
  • 여백이 매우 넉넉하다. 한 화면에 메시지 하나.

3. 타이포그래피

역할크기/행간굵기
히어로 제목56px/66px600
타일 제목40px/44px600
히어로 부제28px/35px, 자간 +0.007em400
본문17px (기본 크기)400
보조·메타19px/14px/12px, 회색 #6E6E73400
  • 본문 기본 크기가 16px이 아니라 17px. 내비와 각주는 12px.
  • 굵기는 400과 600 두 단계. 700은 거의 안 쓴다.
  • 제목은 행간을 좁게(약 1.1~1.18), 본문은 넉넉하게(약 1.47).

4. 색

용도값
글자#1D1D1F (거의 검정), 보조 #6E6E73, #333336
바탕#FFFFFF, 면 구분 #F5F5F7, 어두운 섹션 #000000
어두운 섹션 글자#F5F5F7
강조·버튼파랑 #0071E3, 어두운 바탕 위 링크 #2997FF, 밝은 바탕 위 링크 #0066CC
반투명 글자rgba(0,0,0,.56) / .72 / .8 — 회색을 불투명도로 만든다
  • 회색을 불투명도로 표현해서 어떤 배경 위에서도 자연스럽게 섞인다.
  • 파랑 한 가지만 상호작용 색으로 쓴다. "누를 수 있는 것 = 파랑" 규칙이 일관된다.

5. 컴포넌트

  • 버튼: 완전 알약형(border-radius: 980px), 높이 44px, 패딩 11px 21px, 글자 17px.
    • 주 버튼 = 파랑 채움 + 흰 글자, 보조 버튼 = 투명 + 파랑 1px 테두리 + 파랑 글자.
    • 작은 크기(높이 36px, 14px 글자)도 같은 모양으로 축소.
  • 그림자: 메인 페이지에서 0개. 깊이는 색 면과 사진으로만 표현.
  • 모서리: 버튼 외에는 5px 정도로 아주 작게만.

6. 모션

  • 전환 시간이 세분화돼 있다: 0.18s · 0.22s · 0.24s · 0.32s.
  • 빠르고 짧은 전환을 일관되게 쓴다. 스크롤에 따라 콘텐츠가 늦게 불러와진다(lazy load).

7. 접근성 관찰

  • lang="ko-KR". 버튼 높이 44px로 권장 터치 크기 충족.
  • 밝은 바탕 링크는 #0066CC, 어두운 바탕 링크는 #2997FF로 배경에 따라 대비를 맞춘다.
  • 이번 조사에서 본문 건너뛰기 링크는 찾지 못했다.

8. 우리 대시보드에 가져올 점

  1. 얇은 고정 반투명 내비(44px + blur): 세 페이지 상단 탭 메뉴에 적용. 스크롤해도 항상 이동 가능.
  2. 주/보조 버튼 = 채움/테두리 알약, 높이 44px: 접근성 기준(44px)과 그대로 맞는다.
  3. 상호작용 색 한 가지: 누를 수 있는 것과 현재 상태 강조만 강조색.
  4. 다크 섹션 활용: 영상·카메라 화면 같은 미디어 영역은 검정 바탕 무대에 올리면 집중된다.
  5. 회색은 불투명도로: 라이트/다크 모드 모두에서 자연스럽다.
  6. 본문 17px, 굵기 400/600: 가독성이 좋고 인상이 가볍다.
  7. 배경에 따라 강조색 밝기를 바꿔 대비를 지킨다(라이트 #0066CC / 다크 #2997FF).
